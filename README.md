# VeriPantry
Before the Agent Era arrives, establish the security and access protocols for APIs in the food wholesale marketplace, enabling AI Agents to deliver an end-to-end automated experience: product discovery, order placement, human approval decisions, and intelligent alternative recommendations.

| Folder | What |
|---|---|
| `docs/` | Design specifications (trust protocol, fulfilment, guardrails, audit, frontend) |
| `backend/` | The agent gateway (FastAPI) |
| `agent/` | Stub buyer agent (no LLM yet) |
| `frontend/` | Web app: buyer flow, approvals, audit, recording layout |

**Run the demo with one command:** `py run_demo.py` (Windows) or `python3 run_demo.py` (macOS/Linux). See [`JUDGES.md`](JUDGES.md) for what to try.
